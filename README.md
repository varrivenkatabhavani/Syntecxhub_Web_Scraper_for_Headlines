# Web Scraper for Headlines

## Description
A Web Scraper for Headlines is a Python-based application used to collect headlines from websites automatically using web scraping techniques and store them into a CSV file.

## Features
- Extract Website Headlines
- Store Headlines in CSV File
- Automatic Data Collection
- Beginner-Friendly Project
- Simple Web Scraping
- Input Validation

## Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV Module
- Command Line Interface (CLI)

## How to Run

1. Install Python

2. Install required libraries:

```bash
pip install requests beautifulsoup4
3.Save the file as news_scraper.py
4.Open terminal or command prompt
5.Run the program:
Bash
python news_scraper.py
